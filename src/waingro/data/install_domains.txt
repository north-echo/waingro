# Domain reputation for curl-pipe-shell and remote-fetch rules.
#
# Two tiers, because they are not the same claim:
#
#   vendor   The domain is controlled by the project that publishes the
#            installer. Piping it to a shell is the documented install path.
#            Findings are suppressed to informational.
#
#   usercontent
#            The host is reputable but the *content* is user-supplied: anyone
#            can put a payload there. Findings are kept, at reduced severity,
#            because the domain says nothing about the script.
#
# Anything not listed here keeps full severity.
# Format: <tier> <domain>.  Subdomains of a listed domain match.
